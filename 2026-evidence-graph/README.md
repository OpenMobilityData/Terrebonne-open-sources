# Evidence graph: public statements, documents, data, numerical assertions and assertions on the Terrebonne winter conversion

**Issuer:** the repository's author (a resident of Côte-des-Neiges–Notre-Dame-de-Grâce), from public records. **Date:** started October 20, 2026; updated as the record grows. **Status:** a working map, not a finished document.

**Browse it:** https://openmobilitydata.github.io/Terrebonne-open-sources/2026-evidence-graph/evidence_graph.html (click a node for its full text, its source and its links, each with an arrow to the other end's source; double-click a node or a line to open the source it rests on; "Columns by type" orders each column by date, with the October 6 statements in one column per exchange (the address, then each questioner in webcast order) and rows spaced to each label's height; "Force layout" shows the clusters). Static drawing: [`evidence_graph.svg`](evidence_graph.svg) / [`evidence_graph.png`](evidence_graph.png).

## What it is

A graph kept as data: [`nodes.csv`](nodes.csv) (one row per statement, document, table, numerical assertion, assertion, agent or event, with its date and its source: page of an access-request bundle, recording time stamp, or file) and [`edges.csv`](edges.csv) (one row per relation; a `note` column states the point of difference for every `differs_from`, `unsupported_by` and `does_not_include` edge, shown in the page's side panel and as a tooltip in the SVG; an optional `url` column gives the page or moment that the relation rests on, when it differs from the linked node's own source). [`render_graph.py`](render_graph.py) draws both renderings from the two files (Graphviz; Cytoscape.js).

Every statement node quotes words checked by ear against the recording and gives the time; every document and data node gives the page or file; every numerical-assertion node shows its arithmetic in its label. Relations are a closed list of factual verbs: `attributed_to`, `contained_in`, `released_in`, `withheld_in`, `redacted_in`, `summarized_in`, `precedes`, `implements`, `computed_from`, `states` (a statement puts forward a numerical assertion, or asserts an assertion), `matches` (a statement agrees with a data source), `refers_to`, `echoes`, `sets_aside`, `made_at` (a statement at the sitting, interview or meeting where it was made), `supports`, `undercuts`, `bears_on` (evidence and an assertion), `same_day`, `does_not_include`, `unsupported_by` (a stated figure for which the released record holds no count), `differs_from` and `same_data_other_denominator` (two figures from the same data, two readings). No relation expresses a judgment or a motive.

| Node type | Meaning |
|---|---|
| `agent` | who produced or said something |
| `document` | a dated document, released, withheld or redacted |
| `data` | a table or dataset, or a documented absence of one |
| `numerical assertion` | a number put forward in the debate or derived here from the released data, with the operation that produces it shown in its label; the `states` edges say who put it forward, `computed_from` says what it rests on |
| `assertion` | an unattributed proposition that the evidence bears on, worded so that it could be true or false (« The one-direction layout will become year-round »); never a conclusion about a person. Evidence links to it with `supports`, `undercuts` or `bears_on`; a statement or document that asserts it links with `states`. The graph shows what stands on each side and gives no verdict |
| `statement` | a dated public statement, quoted, with its time stamp |
| `event` | a dated step in the process |

## Querying and adding (tools, October 23, 2026)

The CSV files stay the source of truth; the tools read and write them and nothing else.

- **Columns `time` and `lang`** (nodes.csv, added October 23): `time` is the moment in the recording that the node's link opens (webcast time `H:MM:SS`, or the *Daybreak* audio time `MM:SS`), filled for the 94 statements whose link or source carries one; it is the start of the turn or passage, so it can precede the quoted sentence by a few seconds (the label gives the quoted moment). `lang` is the language of the quoted words (`fr`, `en`, or `fr, en`), filled for the 60 statements added since October 22.
- **SQLite copy.** Every run of `render_graph.py` also writes `evidence_graph.sqlite` (not committed; regenerated from the CSVs, never edited): tables `nodes` (the CSV columns plus `time_s`, seconds into the recording), `edges` (plus `row`, the line in edges.csv), `questions` and `question_nodes`.
- **Saved queries** in [`queries/`](queries/), run with `python3 query_graph.py <name> [value | key=value]` (rebuilds the copy first if the CSVs are newer; `--csv` for CSV output, `--full` for uncut cells; with no argument it lists the queries; `--sql "…"` runs an ad hoc query):
  - `statements_by_agent [agent=…]`: statements by agent and date (an agent id or part of its name);
  - `assertion <id>`: everything that states, supports, undercuts or bears on one assertion (e.g. `x_done_deal`, `x_decided`, `x_reopen`), with the notes;
  - `assertions`: every assertion with the count on each side and its questions;
  - `differs_from [relation=…]`: every `differs_from` pair with its note (or another difference relation);
  - `sitting <event>`: the statements of one sitting or interview in recording order (`e_oct6`, `e_sept8`, `e_agglo_oct22`, `e_daybreak`);
  - `question [<number>]`: the nodes of each question in `questions.csv`;
  - `node <id>`: one node and all its relations.
- **Adding.** `python3 graph_add.py statement --id … --short … --label … --date … --source … --url … --speaker <agent> --event <event> --transcript <document> [--lang …] [--edge RELATION:TARGET[:NOTE]]` adds a statement with its `attributed_to`, `made_at` and `contained_in` relations in one command (`time` taken from the link's `&t=`); `graph_add.py node --type …` adds any other node with its edges; `graph_add.py edge FROM TO RELATION [--note …] [--url …]` adds one relation. It refuses an id already present, an unknown node or relation, an edge already present, a difference relation without a note, and any addition that would leave a new validation problem; nothing is written unless every check passes (`--dry-run` shows the rows). The validator then runs; `render_graph.py` redraws the page.

## Reproduce

`python3 render_graph.py` in this folder (needs Graphviz `dot`). Structure checks and the SQLite copy are in [`graph_lib.py`](graph_lib.py). The page loads Cytoscape.js 3.30.2 from cdnjs and has its data embedded; nothing else is fetched.
